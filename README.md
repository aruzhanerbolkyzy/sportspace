# SportSpace

Веб-система бронирования спортивных площадок. Клиент выбирает площадку, смотрит свободное время и отправляет заявку на бронь. Администратор подтверждает или отклоняет заявки и управляет площадками, часами работы и закрытиями.

**Статус проекта:** в разработке (спроектирована архитектура, код пишется).

## Какую проблему решает

Бронирование по телефону и в мессенджерах приводит к путанице: две команды приходят на одно поле в одно время, администратор забывает записи, клиент не знает, подтверждена ли бронь. SportBook показывает свободное время в календаре, не даёт сделать пересекающиеся брони и хранит все заявки со статусами в одном месте.

## Роли

| Роль | Что может |
|---|---|
| Гость | Смотреть площадки и календарь, регистрироваться, входить |
| Клиент | Бронировать, видеть и отменять свои брони |
| Администратор | Управлять площадками, часами работы, выходными, подтверждать и отклонять заявки |

## Возможности первой версии (MVP)

- Регистрация и вход (JWT).
- Список площадок с фильтром по виду спорта.
- Календарь свободного времени площадки.
- Создание брони, личный кабинет, отмена брони.
- Админ-панель: площадки, часы работы, выходные и закрытия, подтверждение заявок.

Не входят в первую версию: онлайн-оплата, уведомления, отзывы, повторяющиеся брони.

## Технологии

- **Клиент:** React (Vite)
- **Сервер:** Node.js + Express
- **База данных:** PostgreSQL
- **ORM:** Prisma

## Запуск (будет дополнено по мере разработки)

1. Скопировать `.env.example` в `.env` и заполнить значения (`DATABASE_URL`, `JWT_SECRET`, `PORT`).
2. Установить зависимости в папках `client` и `server`.
3. Применить миграции Prisma к базе PostgreSQL.
4. Запустить сервер и клиент.

Точные команды появятся здесь, когда будет готов код.
